💦Consumo de água💦

Este sistema tem o funcionamento de avisar caso a água gasta ultrapassa 25 m3, também tendo uma resposta única para contar abaixo de 10m3, 10 e 25m3 e maior que 25m3 como dito acima.

![Static Badge](https://img.shields.io/badge/economia-Consumo_de_água-green)

Para utilizar o programa basta responder o que se pede, sem a necessidade de colocar m3, pois o próprio sistema já reconhecerá o número e responderá
